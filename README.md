# Chalet Landing Page
واجهة موقع فاخرة لشاليه باستخدام HTML/CSS/JavaScript فقط.

## التشغيل
افتح `index.html` مباشرة أو ارفع جميع الملفات إلى GitHub Pages.

## قبل إرسال الموقع للعميل
- غيّر اسم الشاليه.
- غيّر رابط واتساب في `index.html`.
- أضف السعر/الموقع/الخدمات حسب بيانات العميل.
- استبدل الصور إذا لزم.
